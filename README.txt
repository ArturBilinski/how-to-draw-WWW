# Drawing Books — GitHub Pages

Upload every file from this package to the root of one GitHub repository.

Then open:
Settings → Pages → Build and deployment
Source: Deploy from a branch
Branch: main
Folder: / (root)

Important:
- Keep `index.html` in the repository root.
- Keep all image/video files next to `index.html`.
- The Amazon buttons are intentionally placeholders until real product URLs are added.
- The newsletter form is only a front-end demo and does not send/store email addresses.
